# Dashboard Specification

Implementation: `HELIXNID_EMPIRICAL_LANE_ONE/product_5_6/06_dashboard/`

Shows:
- shipments scored
- high-risk count
- average correction
- locked empirical reduction
- shipment scoring form
- original ETA
- corrected ETA
- late probability
- risk band
- confidence
- historical support
- warning window
- recent shipments
- dataset hash and proof panel

The browser calls the API. HELIXNID scoring logic is not duplicated in JavaScript.
