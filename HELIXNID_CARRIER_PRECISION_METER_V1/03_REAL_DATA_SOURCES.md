# Real Data Sources

## Olist — primary delivery-promise evidence
Real anonymized e-commerce orders containing estimated delivery date and actual delivery timestamp.

## LaDe-D — independent industry replication
Real last-mile industry task-event data published by Cainiao-AI. The public dataset describes about 10.677 million packages and 21,000 couriers over six months. V1 uses the Jilin delivery slice for an independent accept-to-delivery timing benchmark.

## Amazon Last Mile Routing Research Challenge — route precision
Real historical Amazon driver routes. HELIXNID uses 6,112 historical training routes and 3,072 held-out evaluation routes in the existing route benchmark.
